1. RStudio: Source and Console

Source is where you write and save code. Console is where R executes code. Run a line from Source with Ctrl + Enter (Windows) or Command + Enter (Mac).

2 + 2
10 / 2
5 * 6

2. Objects

Objects let R remember values. The assignment operator <- means “store this value under this name.”

x <- 10
x

y <- 5
x + y
object_name <- value

3. Vectors and Functions

A vector stores several values together.

ages <- c(18, 19, 20, 21, 22)

ages
mean(ages)
min(ages)
max(ages)
length(ages)

The basic pattern is function(object).

4. A Tiny Survey

survey <- data.frame(
  id = 1:10,
  gender = c(
    "Woman", "Man", "Woman", "Man", "Woman",
    "Man", "Woman", "Man", "Woman", "Man"
  ),
  approve = c(1, 0, 1, 1, 1, 0, 0, 1, 1, 0),
  age = c(22, 31, 27, 45, 38, 51, 29, 34, 42, 25)
)

survey

A data frame is like a spreadsheet: rows are observations/respondents and columns are variables.

10. Summarizing and Comparing Groups

survey |>
  summarize(
    approval = mean(approve)
  )

One group:

survey |>
  filter(gender == "Woman") |>
  summarize(
    approval = mean(approve)
  )

Both groups at once:

survey |>
  group_by(gender) |>
  summarize(
    approval = mean(approve)
  )

12. Missing Values

Missing values are represented by NA.

survey$age[3] <- NA

mean(survey$age)

Remove missing values from a calculation with:

mean(survey$age, na.rm = TRUE)

15. Common Errors

object not found

Check spelling, capitalization, and whether you actually ran the line that created the object.

could not find function

Make sure the needed package is loaded, for example library(tidyverse).

File does not exist

getwd()
list.files()

Capitalization matters

survey
Survey
SURVEY

R is case-sensitive.

Debug one step at a time

Run one line, confirm that it works, then move to the next.

17. Transfer to the Texas Poll

Download the Texas poll CSV · Open the codebook

texas <- read_csv("texas_poll.csv")
names(texas)

Create the Latino analytic sample:

latino <- texas |>
  filter(!is.na(weight_hisp))

Inspect the governor vote variable:

latino |>
  count(govvote26_full)

Create a 0/1 Hinojosa indicator:

latino <- latino |>
  mutate(
    hinojosa = if_else(
      govvote26_full == 1,
      1,
      0,
      missing = NA_real_
    )
  )

Calculate unweighted support:

latino |>
  summarize(
    support = mean(
      hinojosa,
      na.rm = TRUE
    )
  )

Compare by gender:

latino |>
  group_by(gender) |>
  summarize(
    support = mean(
      hinojosa,
      na.rm = TRUE
    )
  )
These are unweighted practice estimates. The weighting lab shows how to produce survey estimates for substantive reporting.
