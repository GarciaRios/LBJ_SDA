Lab 3: From a Sample to an Estimate

Sampling variability, confidence intervals, and subgroup comparisons

Purpose

Poll estimates change from sample to sample even when nothing about the population has changed. Statistical inference helps us describe that expected variation and decide how much uncertainty surrounds an estimate.

In this lab, we will keep the R code simple and focus on the statistical logic. We will:

  1. simulate a Texas poll;
  2. repeat the poll many times;
  3. see a sampling distribution;
  4. calculate a standard error and margin of error;
  5. construct a confidence interval; and
  6. compare two subgroups in the October 2026 Univision/YouGov Texas Poll.
Important

For now, we use formulas that treat observations as if they came from a simple random sample. This is a teaching simplification. The Texas poll uses weights and a more complex design. Lab 4 will return to this same poll and introduce weighted, design-aware estimates.

Learning objectives

By the end of this lab, you should be able to:

  • explain why two samples from the same population can give different estimates;
  • distinguish a population parameter from a sample estimate;
  • explain a sampling distribution;
  • interpret a standard error;
  • calculate an approximate margin of sampling error;
  • construct and interpret a 95% confidence interval;
  • explain why larger samples generally produce more precise estimates;
  • compare two subgroup proportions; and
  • explain what sampling uncertainty does not capture.

Part I: Why poll estimates vary

1. Setup

We only need the tidyverse package.

library(tidyverse)

set.seed(20261102)

set.seed() makes the random simulation reproducible.

2. Imagine the Texas electorate

Suppose that in the full population of Texas voters, exactly 50% support a candidate.

p_true <- 0.50

This is the population parameter.

In a real poll, we do not know the true population value. That is why we take a sample.

3. Conduct one simulated Texas poll

The October Univision/YouGov Texas poll interviewed about 1,000 voters statewide.

Let’s simulate a poll with 1,000 respondents.

support <- rbinom(
  1000,
  1,
  0.50
)

Each simulated respondent receives:

  • 1 = supports the candidate
  • 0 = does not support the candidate

Calculate the sample estimate:

mean(support)

Because the variable contains only 0s and 1s, the mean is the proportion who support the candidate.

4. Conduct the poll many times

Now imagine conducting the same 1,000-person poll 500 times.

estimates <- replicate(
  500,

Look at the first several estimates:

The estimates are not identical. Their distribution is called a sampling distribution.

Part II: Standard errors and confidence intervals

5. Standard error

The standard error describes how much an estimate would vary across repeated samples.

For a proportion:

\[ SE(\hat{p}) = \sqrt{\frac{\hat{p}(1-\hat{p})}{n}} \]

Return to our first simulated poll.

p_hat <- mean(support)

Calculate its standard error:

se <- sqrt(
  p_hat * (1 - p_hat) / 1000
)

se

Compare it with the variability across our 500 simulated polls:

sd(estimates)

They should be fairly similar.

Checkpoint 3: In plain language, what does the standard error describe?

Your response:

6. Margin of error

For a 95% confidence interval, an approximate margin of sampling error is:

\[ 1.96 \times SE \]

Calculate it:

moe <- 1.96 * se

moe

Convert it to percentage points:

moe * 100
Note

This is a margin of sampling error under the simple assumptions used here. It is not a measure of total survey error.

7. Build a 95% confidence interval

Calculate the lower and upper bounds:

lower <- p_hat - moe
upper <- p_hat + moe

Display them:

tibble(
  estimate = p_hat,
  lower = lower,
  upper = upper
)

Checkpoint 4: Write the result as you might report it in a poll story.

Support is estimated at XX%, with an approximate 95% confidence interval from XX% to XX%.

Your response:

8. What does 95% confidence mean?

A 95% confidence procedure is designed so that, across many repeated samples, about 95% of the intervals produced by the procedure will contain the true population value.

It does not mean that 95% of respondents fall inside the interval.

It also does not mean that there is a 95% chance that this one fixed interval contains the population value.

We can see the repeated-sampling idea directly.

Calculate a standard error for each of our 500 simulated polls:

sim_se <- sqrt(
  estimates * (1 - estimates) / 1000
)

Calculate 500 lower and upper bounds:

sim_lower <- estimates - 1.96 * sim_se
sim_upper <- estimates + 1.96 * sim_se

Check how often the intervals contain the true value of 0.50:

mean(
  sim_lower <= 0.50 &
  sim_upper >= 0.50
)

The result should be close to 0.95.

Part III: Why sample size matters

9. Compare a small and large poll

First simulate 500 polls with only 250 respondents:

small_polls <- replicate(
  500,
  mean(rbinom(250, 1, 0.50))
)

Now simulate 500 polls with 2,000 respondents:

large_polls <- replicate(
  500,
  mean(rbinom(2000, 1, 0.50))
)

Compare the spread of the estimates:

sd(small_polls)
sd(estimates)
sd(large_polls)

Remember:

  • small_polls uses n = 250
  • estimates uses n = 1,000
  • large_polls uses n = 2,000

Checkpoint 6: What happens to sampling variability as sample size increases?

Your response:

Warning

A larger sample reduces sampling variability.

It does not automatically fix:

  • coverage error;
  • nonresponse bias;
  • self-selection;
  • measurement error;
  • weighting problems; or
  • poor respondent quality.

A large sample can still give a very precise estimate of the wrong quantity.

Part VI: Compare Latino men and women

15. Create a gender variable

In this dataset:

  • 1 = men
  • 2 = women
latino <- latino |>
  mutate(
    gender_group = case_when(
      gender == 1 ~ "Men",
      gender == 2 ~ "Women",
      TRUE ~ NA_character_
    )
  )

Check the result:

count(latino, gender_group)

16. Calculate support within each group

gender_results <- latino |>
  filter(
    !is.na(gender_group)
  ) |>
  group_by(gender_group) |>
  summarize(
    n = sum(!is.na(hinojosa)),
    estimate = mean(
      hinojosa,
      na.rm = TRUE
    )
  )

gender_results

Add a standard error and confidence interval:

gender_results <- gender_results |>
  mutate(
    se = sqrt(
      estimate * (1 - estimate) / n
    ),
    lower = estimate - 1.96 * se,
    upper = estimate + 1.96 * se
  )

gender_results

Create a simple figure:

ggplot(
  gender_results,
  aes(
    x = gender_group,
    y = estimate,
    ymin = lower,
    ymax = upper
  )
) +
  geom_pointrange() +
  scale_y_continuous(
    labels = scales::percent
  ) +
  labs(
    title = "Hinojosa support among Latino voters",
    subtitle = "Unweighted October 2026 Texas poll",
    x = NULL,
    y = "Estimated support"
  ) +
  theme_minimal()

Part VII: Estimate the difference

17. Pull out the two groups

men <- gender_results |>
  filter(gender_group == "Men")

women <- gender_results |>
  filter(gender_group == "Women")

Calculate the difference:

difference <-
  women$estimate -
  men$estimate

difference

A positive value means Hinojosa support is higher among women in this sample.

18. Calculate uncertainty around the difference

se_difference <- sqrt(
  women$estimate *
    (1 - women$estimate) /
    women$n +
  men$estimate *
    (1 - men$estimate) /
    men$n
)

Calculate the confidence interval:

difference - 1.96 * se_difference
difference + 1.96 * se_difference

Interpretation:

  • If the interval includes 0, the observed difference is compatible with no population difference under this simple model.
  • If the interval does not include 0, the data provide evidence that the population proportions differ under this simple model.
Tip

This is the same basic logic behind a two-sided hypothesis test. For this course, focus first on the size of the difference and the uncertainty around it rather than memorizing a p-value rule.

Checkpoint 9: Does the interval include zero? What is the most defensible conclusion?

What a confidence interval does not tell us

A confidence interval addresses uncertainty from the sampling process under a statistical model.

It does not automatically account for:

  • coverage error;
  • nonresponse bias;
  • measurement error;
  • mode effects;
  • self-selection;
  • weighting error;
  • respondent-quality problems; or
  • mistakes in coding and analysis.

That is why a narrow confidence interval does not automatically imply a high-quality survey.
